# Instancias TSP

Conjunto de instancias simetricas da TSPLIB95 em formato `.tsp`, baixadas do
espelho publico <https://github.com/mastqe/tsplib>.

Classificacao adotada:

- pequenas: ate 100 cidades;
- medias: de 101 a 300 cidades.
