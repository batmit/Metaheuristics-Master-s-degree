# Histórico do projeto

`pesquisas_e_versoes_anteriores.zip` preserva os experimentos, fontes, relatórios
e módulos retirados da estrutura ativa. A integridade de todas as entradas foi
verificada antes da limpeza. `MANIFESTO.json`, dentro do ZIP, registra nomes,
tamanhos e hashes SHA-256; `fontes_antes_limpeza/` contém o núcleo antes desta
refatoração. A avaliação de velocidade anterior está em
`resultados/avaliacao_velocidade_20261106/` dentro do arquivo.

O conteúdo é material de pesquisa e reprodução histórica. Para consultar,
extraia o ZIP para uma pasta separada. O programa atual usa somente os arquivos
ativos descritos no README da raiz e não consulta esse histórico.

A comparacao detalhada da limpeza esta em `verificacao_limpeza/`, com um
manifesto complementar para essas entradas e as antigas tabelas de literatura.
