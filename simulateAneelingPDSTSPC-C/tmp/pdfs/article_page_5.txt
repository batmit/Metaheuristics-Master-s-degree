2.2. A Constraint Programming model
The Constraint Programming model we present is based on the Google-
OR CP-SAT solver [22] and follows the ideas behind the Mixed Integer Linear
Program described in [17]. In particular, drone missions are modeled through
a flow. Changes have however been introduced to take full advantage of the
characteristic of the solver used.
The variables used in the model are as follows:
• xij: binary variables equal to 1 ( true) if edge ( i, j), with i, j ∈ C , is
traveled by the truck, 0 ( false) otherwise. Whereas a loop xjj = 1 means
that customer j is served by drones, while xjj = 0 if it is served by the
truck.
• zk
j : binary variables equal to 1 if customer j ∈ C F is served by k drones,
0 otherwise.
• yij: binary variables equal to 1 if customeri is served right before customer
j within the schedule of any drone, 0 otherwise.
• fij ∈ R+: continuous flow variables indicating number of drones serving
customer i right before customer j in their schedule.
